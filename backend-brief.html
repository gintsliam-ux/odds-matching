closed · 8 Oct 13,409 documents · ~95% of writes

The fixture writer does not key on fixture_id

Fixtures are inserted without setting _id to the fixture_id and without upserting on it, so a re-run writes a second document rather than updating the first. There is no unique index to stop it. 855 ids had collided before today.

The change, and a warning about the order

Upsert on fixture_id and set _id to it. Then db.fixtures.createIndex({ fixture_id: 1 }, { unique: true }) — but fix the writer first. With the index in place and the writer unchanged, the duplicate insert throws E11000 instead of duplicating, which turns silent corruption into a stopped feed. The index also will not build until the 93 remaining duplicates are resolved.

closed · 8 Oct one batch = 26 splits, 15,499 fixtures

An id migration moves optic_league but not tournament

Migrated fixtures carry their old tournament name onto the new id, so every batch recreates the splits. The batch between 2 and 8 October produced 26 of them.

The change

{ $set: { optic_league: newId, tournament: leaguesRow.tournament } } — one extra field, and the follow-up pass stops being needed at all.

One correction to the 1 Oct brief

I reported has_odds as wrong on 16,820 fixtures and changed them. That was my error: the flag means currently open for betting, not has pregame odds on file, so a settled fixture with archived prices is correctly false. Something recomputed it within hours and the count is back to normal. No action needed, and the flag was never broken.

The tooling, if you want to run it yourselves

All in odds-matching-mongo/scripts/, all read-only or dry-by-default: audit-integrity.mjs (whole-DB sweep, --json), audit-stranded-ids.mjs (--csv), audit-coverage.mjs (missing months per league), dedupe-fixtures.mjs (--resolve --apply), and merge-tournament-names.mjs with six passes.

Two traps they encode, both of which produced confident false positives before being filtered: national sides share their names across formats and genders, so team overlap reads ~100% between a men's and a women's competition or a qualifier and its final; and a short league id reduces to tokens that sit inside every similar one — soccer_fa_cup matched Belgium's, Bangladesh's and Spain's cups alike.
